# Historical evidence analyst playbook

## Scope
Assess historical comparables, prior outcomes, and their limitations.

## Required Inputs
Evaluation ID, normalized snapshot, and requested question.

## Output Contract
Return bounded claims, source IDs, applicability, uncertainty, and lesson proposals.

## Failure States
Return insufficient evidence or non-comparable history; do not infer missing facts.

## Non-responsibilities
No current market substitution, strategy selection, memory writes, browser sessions, or orders.
