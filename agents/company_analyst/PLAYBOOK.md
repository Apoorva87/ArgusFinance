# Company analyst playbook

## Scope
Assess company fundamentals, catalysts, and issuer disclosures as evidence.

## Required Inputs
Evaluation ID, normalized snapshot, and requested ticker scope.

## Output Contract
Return bounded claims, source IDs, applicability, uncertainty, and lesson proposals.

## Failure States
Return insufficient evidence or source conflict; do not infer missing facts.

## Non-responsibilities
No prices, strategy selection, memory writes, browser sessions, or orders.
