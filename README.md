# ArgusFinance

ArgusFinance is a local-first, agent-orchestrated investment research and
options decision workbench. It is designed to help a user explore option
structures, preserve investment theses and strategy history, monitor saved
positions, and understand possible adjustments through an auditable visual
decision surface.

The project is currently in the design phase. See
[`docs/superpowers/specs/2026-08-30-argusfinance-design.md`](docs/superpowers/specs/2026-08-30-argusfinance-design.md)
for the approved architecture.

ArgusFinance does not place live orders. Brokerage access is read-only in V1,
and every recommendation remains subject to user review.
